# Sitios web

Dos sitios independientes en español. Cada carpeta contiene todos los archivos que necesita su sitio. Para probar cualquiera de ellos, abre su `index.html` o sirve esa carpeta con un servidor estático.

| Sitio | Carpeta |
| --- | --- |
| Globalservices · Electricidad y automatización industrial | [`globalservices/`](globalservices/) |
| Serviteca Magallanes · Mantención automotriz | [`serviteca-magallanes/`](serviteca-magallanes/) |

El sitio de Globalservices prepara localmente un resumen del requerimiento. Falta confirmar el canal de contacto de la empresa. En el sitio de Serviteca, WhatsApp abre un mensaje para que el visitante lo revise y envíe desde su cuenta.

Los datos de atención del taller se consultaron en el [sitio de Serviteca Magallanes](https://www.servitecamagallanes.cl/).
